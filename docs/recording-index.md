## 缺失原因与恢复方式

本次通过 Codex 发起实现，没有启动屏幕录制工具。不能伪造录像、时间、时长或上传链接。源码、过程文档和自动测试可供核查，但不能替代 PDF 要求的屏幕记录。

后续可真实录制候选人复核、解释、修改和最终演示，从开始录制时起连续记录，并明确属于后续阶段。是否接受此前缺失应按招聘方要求处理；本项目不宣称“录屏交付完成”。

## 后续填写规则

- 从 `recordings/001.mp4` 起顺序命名，原速连续，不以剪辑演示代替开发。
- 每段填写真实起止时间、总时长、任务及关键事件时间点；中断说明原因、任务和恢复方式。
- 单独录制 10–15 分钟最终演示，使用虚构账号数据，保护无关个人信息。
- 如单独上传，补充真实、授权可访问的链接和访问方法；目前无可用外链。
- 打包脚本不会自动包含视频，须按招聘方要求单独交付或加入压缩包。
