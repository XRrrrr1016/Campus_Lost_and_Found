# 最终演示脚本（建议 10–15 分钟）

这是录制提纲，尚未执行或生成视频。不要将建议时间当成已有录屏索引。

1. **0–2 分钟：启动。** 展示 Python 版本、项目结构、`python app.py`。解释首次幂等初始化及无第三方运行依赖；打开本地地址。
2. **2–4 分钟：发布与筛选。** 访客查看联系方式保护；切换普通用户发布一条失物，再切换拾获者发布对应招领，含图片和未公开特征。组合筛选类别、日期、状态，演示无结果提示。
3. **4–7 分钟：匹配与核验。** 失主选择本人失物 → 智能匹配 → 阅读各字段依据/规则版本 → 申请认领并关联失物。说明公开照片不要含核验答案。通过前不能获取联系方式。
4. **7–9 分钟：交接。** 拾获者看到特征核验标志 → 通过 → 双方可见联系人 → 实际交接确认 → 物品/失物/申请共同结案。
5. **9–11 分钟：异常与审计。** 另一件招领使用错误答案，尝试通过被禁止，填写原因驳回。演示普通用户不能发布规则、不能审核他人记录；删除开放记录留下审计。
6. **11–13 分钟：规则与复算。** 管理员改变权重/禁用某字段，发布新版本；原推荐历史复算依然完全相同。解释保存了什么、不保存什么。
7. **13–15 分钟：测试与限制。** 执行 `python -m unittest discover -s tests -v` 和 `python scripts/evaluate_ai.py`。展示三类样例与信息不足拒判；说明离线模拟器、无图像匹配、无生产身份体系、录屏此前缺失。结束录制并填写真实索引。
