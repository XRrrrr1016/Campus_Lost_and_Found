关键边界的具体断言包括：

- `test_full_handover_links_lost_and_found`：申请者不能自行确认交接；批准后关联失物为 `reserved`，交接后招领/失物均为 `resolved`、申请为 `completed`。
- `test_concurrent_reviews_have_exactly_one_winner`：两个线程竞争同一招领，恰好一个批准成功，最终申请状态为一个 `approved`、一个 `rejected`。
- `test_rule_history_recomputes_from_immutable_snapshots`：发布新规则、删除候选后旧批次仍与原结果完全一致，无关用户无权复算。
- `test_unlinked_claim_contact_is_private_until_approved`：未关联失物且没有联系方式时拒绝；提交后双方列表不输出申请联系人，批准后拾获者可读取。
- `test_secret_answer_cannot_be_a_public_field`：秘密答案取公开颜色、地点、类别、日期时均不得发布。
- `test_old_database_contact_migration_is_idempotent`：对已批准且关联失物的申请模拟删除联系人列，连续初始化两次后仍可取得旧联系信息。
- `test_required_fields_dates_and_weights_are_validated`：覆盖空秘密答案、倒置日期、非法类型、空标题，以及负数、NaN、未知字段、全零权重；不能据此声称已穷尽所有输入边界。

持久化用例重建 Service 并重新连接同一文件；它不是浏览器关闭服务后重新启动的完整端到端重启测试。跨进程初始化结果另见本节历史交付验证。

**浏览器实际流程**

脚本在独立临时库启动服务，首次有 8 条样例，并实际执行：

1. 访客打开广场，选择“待认领”筛选，返回条数与原开放记录数一致。
2. 切换 `alice`、`bob`，分别填写并发布新的失物/招领；招领附一个小型 PNG 样例，服务创建记录成功。
3. `alice` 从自己的新失物发起匹配，能打开对应新招领，详情中没有拾获者联系方式。
4. 填写私密答案和申请联系人，确认默认关联到自己的失物并提交。
5. `bob` 进入认领与交接，批准后能看到申请者联系人，确认交接后页面出现 `completed` 状态。
6. `admin` 发布规则后界面显示规则序号 `v2`；`alice` 复算旧批次，页面显示与历史结果完全一致。
7. 获取桌面/匹配/手机截图，将视口改为 390×844，断言页面无横向溢出，未捕获 `pageerror` 异常。

本次浏览器结果为 `passed=true`、`pageErrors=[]`、`mobileOverflow=false`，新建失物 ID 为 9、招领 ID 为 10。对应结果快照保存在随文档保存的[浏览器摘要 JSON](test-evidence/browser-2026-10-27.json)；本地原始结果及截图位于 `output/qa/browser-result.json`、`desktop.png`、`matching.png`、`mobile.png`。`output/` 不进入源码包，可本地查看或复跑脚本重新生成，不能要求包内一定存在这些图片。本次已由 AI 查看桌面/手机截图，没有据此声明所有交互或所有设备已人工验收。

浏览器脚本主要覆盖成功链路，错误特征、越权和并发等由 Python 测试覆盖。上传成功只证明该 PNG 样例可以提交，不证明所有图片都可正确解码或具备内容安全性；`pageerror=[]` 也不等于所有网络/控制台事件均无错误。

## 6. 已知问题

本次执行范围内没有未通过的测试方法或失败的 AI 样例；这不表示已经覆盖所有分支、发现所有缺陷或完成正式人工验收。

- 离线算法依赖有限同义词和字段相似度，词表外改写可能得分偏低；没有真实标注数据上的准确率/召回率证据。
- 说明文字按相似度阈值简化为“一致/接近/存在差异”。例如一天日期误差样例仍可能显示“时间一致”，不代表日期字面完全相同；使用者应查看原始日期并核验。
- 只支持规范化后的精确答案，不支持语义同义回答；每用户对每招领只能申请一次，驳回后不能重提，没有取消、撤销核验、结案重开或发布后编辑。
- 图片上传/展示已实现，图像识别、图片参与匹配、泄密检测和完整内容安全扫描未实现；图片和公开字段是否保留真正的私密特征需要人工复核。
- 列表和单次候选读取最多 500 条，候选取 ID 升序前 500 条后再按分数排序；无分页，不保证更大数据集的完整检索或响应时间。
- 公开演示账号、本地 HTTP 和 SQLite 文件访问控制不等于生产身份体系或静态加密；没有 HTTPS、统一认证、密码找回或登录限流。
- 浏览器脚本覆盖主要成功路径，未对每个错误提示、空结果、焦点行为和所有中文文案做独立断言。AI 查看截图不等于真实用户体验验收。
- 原开发全程和最终演示视频仍未附带，候选人独立人工验收、代码解释及真实编号仍待完成；当前对话和测试日志不能冒充原始录屏。
- 当前已有 ZIP 未同步最近逐份修改的 docs。应在文档齐备后重新生成并独立验证，不能直接使用本次 unittest 的通过结论替代最终包验收。

这些限制与 [01-spec.md](01-spec.md) 一致。未实现的云模型润色、取消、草稿、举报等不列为“测试已通过”，也不把它们按未修复既有功能缺陷记录。
